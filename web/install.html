Get YepControl on your phone

Install the app on the Android phone you want someone to view and control. The device controlling it only needs a browser.

Want to control another phone from this browser?

Open source · View on GitHub · MIT license

After installing

  1. Open YepControl

    Tap Scan browser’s code in the app. In older versions, this is called Scan pairing code.

  2. Scan a fresh code

    Use the code displayed in the browser on your other device. Codes refresh every five minutes. You can also open a pairing link sent from that browser.

  3. Approve the connection

    Check the browser name, then tap Allow on this phone.

Open a pairing link from the controlling browser, or scan its code from inside the app. After installing, get a fresh link or code.

Installing the app does not pair your devices automatically.
