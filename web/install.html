Get YepControl on your phone

Install the app on the Android phone you want someone to view and control. The device controlling it only needs a browser.

Want to control another phone from this browser?

Open source · View on GitHub · MIT license

After installing

  1. Show a code on this phone

    Open YepControl and choose Give control → Show code.

  2. Scan with the other device

    Use its camera. The browser connects automatically.

On older app versions, open yepcontrol.com/pair on the other device and scan its code from the app.
