YepControl

Android 11+ · Free · No invitation needed

Get YepControl on your phone

Install the app on this Android phone to view and control it from your other device’s browser.

Install from Google Play ↗

After installing

  1. Open YepControl

    Tap Scan pairing code in the app.

  2. Scan a fresh code

    Use the code displayed in the browser on your other device. Codes refresh every five minutes.

  3. Approve the connection

    Check the browser name, then tap Grant on this phone.

Already installed? Open YepControl on this phone and scan the code from inside the app.

Installing the app does not pair your devices automatically.
